# Sistema Bancário Simples (Java)

Projeto de estudo feito em Java para praticar lógica de programação, estruturas de repetição, condicionais e métodos.

A ideia é simular um caixa eletrônico básico rodando pelo terminal, com um menu interativo onde o usuário pode ver o saldo, depositar e sacar.

## O que o programa faz

Ao rodar, ele exibe um menu com as opções:
1. Mostrar Saldo
2. Depositar
3. Sacar
4. Sair

- O **saldo** começa em zero.
- No **depósito**, o valor é somado ao saldo (não aceita valores negativos).
- No **saque**, o sistema verifica se há saldo suficiente e se o valor é positivo antes de descontar.
- A opção **Sair** encerra o loop e fecha o programa.
